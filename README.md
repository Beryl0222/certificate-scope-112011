# 跨境委托的双语见证抽样与封样交接

业务交接资料为 UTF-8 JSON，每个文件保存一组记录。全部人名、机构、材料与项目均为虚构。
编号在各自资料中使用。保留原文中的省略、转述、标点和异体字，空字段表示交接中没有填值。

## 交接资料

- `data/orders.json` 保存id、时间、来自、引用、原文。买家委托、转述和后续说明。时间使用同一见证站当地时钟。引用关联原来件。

- `data/inventory.json` 保存id、批、箱、包装、表面、可切片。完整件与箱、批、包装和表面的交接登记。小片编号只在母件内识别。

- `data/lab.json` 保存id、来源、原文。两家实验室的收样约定原文和切片邻接信息。

- `data/handover.json` 保存id、时间、批、母件、封签、动作、片、原文。封签、签收与测试记录。签号可对应多次收发动作。

## 阅读与运行

使用 Python 3.11.2 和标准库。在仓库根目录查看资料目录和一条原始记录。测试检查原文读入及资料关系。

```text
python3 -m corpus
python3 -m corpus orders --id O1
python3 -m unittest discover -s tests -v
```

## 取样交接工具（sampling）

`sampling/` 在不改动原始资料的前提下，把中英指令解读、冲突确认、实物状态重建、
封样/收样分配、复测判定与溯源串成一套可操作工具。所有结论都带原件编号（O/L/H/P/S），
可逐句回到原文；只读 `data/`，见证员确认写入 `work/confirmations.json`（已忽略）。

隔离模式（`-I`）下用根目录的 `run.py`，普通模式也可直接 `python3 -m sampling`：

```text
python3 -I run.py instructions                 # 结构化解读每条来件（数量对象/单位/同源/独立试样/留样）
python3 -I run.py conflicts                    # 列出英文原件与工厂转述中会改变取样的三处冲突
python3 -I run.py conflicts --confirm C1 --witness 王见证   # 见证员确认受影响的一处说法（默认采用买家原件）
python3 -I run.py plan --lot J17               # 逐批分配、可封样/可收样件、缺件及原因、O4 澄清影响
python3 -I run.py plan --lot J18               # 复测触发、同源对照判定与重新见证成套取样
python3 -I run.py inspect                      # 检测员按封签逐项收件结论（可独立开测的不受牵连）
python3 -I run.py inspect --duplicate-slip S05 # 登记西实验室要求的见证副联
python3 -I run.py trace S03                    # 原指令→取样证明→封签→检测用途的完整链路
python3 -I run.py event "透湿读数过低，有完整读数，a 已消耗。"  # 单条原文的复测触发分类
python3 -I run.py test                         # 运行全部测试（含原有资料测试）
```

### 工具落实的关键口径

- **数量对象与单位**：O1 为每批三件完整件且分箱；O2 的“按包装规格各三片/各用一件/留一片”
  被识别为三处会改变取样的冲突，须由见证员逐条确认后计划才脱离草案状态。
- **同源与独立试样**：透湿与剥离共用同一母件，但必须是不同小片（a、b 相邻，a、c 不相邻），
  同一片不得用于两项破坏性检测；MV 耗尽试样。
- **留样与触发**：预留为首次取样即整件另封；仅运输封签破损、透湿无读数让预留进入准备状态，
  读数偏低但有效、已测不合格均不触发，预留不会被自动开封。
- **完整件门**：拟裁切件先做完整状态身份与外观见证；整件外观项不得用已裁切母件代交；
  已拆封或消耗的小片不能按图上余料再分给他用。
- **O4 外层限定（J17）**：外层且封好的件可继续送；内层未测件须解封重取；内层已测件
  结果对本次委托失效且无法补回原状。
- **复测缺样合并（J18）**：同源对照毁损且无同母件可用邻片时，合并判定缺样并请求重新见证
  成套取样，从别箱凑数量没有意义；另箱预留件不能充当同源对照。
- **收件独立性**：按封签各自核对实验室认可的封签形态、表面、小片状态与副联；
  不符部分拒收，能独立开测的照常开测。
