# 跨境委托的双语见证抽样与封样交接

业务交接资料为 UTF-8 JSON，每个文件保存一组记录。全部人名、机构、材料与项目均为虚构。
编号在各自资料中使用。保留原文中的省略、转述、标点和异体字，空字段表示交接中没有填值。

## 交接资料

- `data/orders.json` 保存id、时间、来自、引用、原文。买家委托、转述和后续说明。时间使用同一见证站当地时钟。引用关联原来件。

- `data/inventory.json` 保存id、批、箱、包装、表面、可切片。完整件与箱、批、包装和表面的交接登记。小片编号只在母件内识别。

- `data/lab.json` 保存id、来源、原文。两家实验室的收样约定原文和切片邻接信息。

- `data/handover.json` 保存id、时间、批、母件、封签、动作、片、原文。封签、签收与测试记录。签号可对应多次收发动作。

## 阅读与运行

使用 Python 3.11.2 和标准库。在仓库根目录查看资料目录和一条原始记录。测试检查原文读入及资料关系。

```text
python3 -m corpus
python3 -m corpus orders --id O1
python3 -m unittest discover -s tests -v
```
